# Storyliner

A quest and narrative design tool for games: lay a quest out as a map of scenes, write the dialogue inside it,
and play it as a text game while you write — with the real logic running.

## [Download the newest version](https://github.com/Tvejzer/Storyliner-releases/releases/latest/download/Storyliner-Setup.exe)

For Windows: run the installer; it installs over the version you have. For Linux:
[Storyliner.AppImage](https://github.com/Tvejzer/Storyliner-releases/releases/latest/download/Storyliner.AppImage) — allow it to run as a program, then open it.

## [The guide](guide/README.md)

How to use Storyliner, page by page, with pictures: getting started, writing dialogue, characters, play
mode and the rest. In the app, *Help ▸ Guide* opens it — the guide of the version you have.

- **[All releases](https://github.com/Tvejzer/Storyliner-releases/releases)** — each version, with what changed in it.
- **Updates.** Once installed, Storyliner looks for a newer version as it starts; when there is one, its status

  download the newer one.
